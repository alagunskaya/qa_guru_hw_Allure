# UI-тестирование веб-калькулятора

Проект для демонстрации автоматизации тестирования с использованием **Python**, **Pytest**, **Selenium** и **Allure**.

---

## 🚀 **Быстрый старт**

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```
### 2. Запуск тестов
```bash
pytest
```
### 3.  Просмотр Allure-отчёта
```bash
allure serve allure-results
```
